# Central N2 Web

Aplicação Next.js do frontend da Central N2.

## Desenvolvimento

```bash
npm ci
npm run dev
```

A aplicação abre em `http://localhost:3000`.

## Produção local

```bash
npm run build
npm run start
```

O comando `start` executa o servidor standalone gerado pelo Next.js.

## Qualidade

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
